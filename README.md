# StudyRoomBOT（Python版）

`勉強時間記録` テキストチャンネルへ `開始` と `終了` を投稿して、ユーザーごとの勉強時間を記録するDiscord BOTです。データはギルドごとにSQLiteへ保存します。登録されたVCへの参加時には `勉強中` ロールを付与します。

BOTが停止中に送られた `開始` / `終了` も、次の起動時にテキストチャンネル履歴を読み、その投稿時刻で自動集計します（BOTは過去メッセージへ返信しません）。VCの入退室時刻そのものは、停止中の分を後から復元できません。

## 1. 秘密情報を設定する

Developer Portalの **Bot** ページでトークンを再発行します。`.env.example` をコピーして `.env` へ名前を変え、以下だけを書きます。トークンはGitHubやチャットへ絶対に貼らないでください。

```env
DISCORD_TOKEN=新しく発行したBOTトークン
```

## 2. 必要な設定

Developer Portalの **Bot** ページで、以下を有効にします。

- Message Content Intent（「開始」「終了」を読むため）
- Server Members Intent（ロールの追加・削除に使うため）

インストール時は `bot` と `applications.commands` スコープを選びます。BOT権限には少なくとも「チャンネルを見る」「メッセージ履歴を読む」「メッセージを送信」「埋め込みリンク」「ロールの管理」を与えてください。Discordのロール設定で、BOT自身のロールを `勉強中` ロールより上に置きます。

## 3. ローカルで起動する

```powershell
uv sync
.\.venv\Scripts\Activate.ps1
python bot.py
```

ギルドに `勉強時間記録` というテキストチャンネルを作り、そこで `開始` と入力して試します。BOTが返信したら、`終了` で計測を止めます。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/about` | BOT概要 |
| `/help` | 使い方 |
| `/studydate` | 過去7日の日別・累計・ランク |
| `/studyweek` | 過去5週の週別・累計・ランク |
| `/admin` | 管理者ガイド |
| `/studyroomadd` | 管理者が参加中VCをロール付与対象に登録 |
| `/studyroomdel` | 管理者が参加中VCを対象から解除 |

## 常時運用について

PCを止めるなら、BOTをVPS等の常時稼働するサーバーへ配置する必要があります。SQLiteのファイルを失わないよう、永続ディスクを付けられるVPSを選んでください。サーバーを選ぶ段階で `.env` の値を環境変数 `DISCORD_TOKEN` として登録し、`.env` ファイルはアップロードしません。

無料枠のホスティングは停止・データ消去・稼働時間制限があり、勉強時間管理には向きません。小規模な有料VPSが安定します。
